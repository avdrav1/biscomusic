Get the app

Jam Radio installs straight from your browser, no app store needed. It gets its own icon, opens full-screen, and keeps playing with controls on your lock screen.

You're already in the app. Enjoy the jams.

Safari, Chrome or Edge

  1. Tap the Share button (bottom toolbar in Safari, address bar in Chrome and Edge)
  2. Scroll down and tap Add to Home Screen
  3. Leave Open as Web App on and tap Add

Don't see Add to Home Screen? Tap Edit Actions at the bottom of the share sheet and add it.

Chrome

  1. Tap the ⋮ menu (or the Install button above, when it shows)
  2. Tap Add to Home screen, then Install
  3. Jam Radio shows up with your other apps

Samsung Internet

  1. Tap the install icon in the address bar, or open the ≡ menu
  2. Tap Add page to, then Home screen

Firefox

  1. Tap the ⋮ menu
  2. Tap Add app to Home screen (or Install)

Safari

  1. In the menu bar, choose File › Add to Dock… (or use the Share button)
  2. Click Add. Jam Radio is in your Dock and Launchpad

Needs macOS Sonoma or newer.

Chrome

  1. Click the install icon at the right end of the address bar (or the Install button above)
  2. No icon? ⋮ › Cast, save, and share › Install page as app…

Edge

  1. Click the App available icon in the address bar, or … › Apps › Install this site as an app

Firefox

Firefox on Mac can't install web apps yet. Open biscomusic.com in Safari or Chrome and follow the steps above.

Edge

  1. Click the App available icon in the address bar (or the Install button above)
  2. No icon? … › Apps › Install this site as an app
  3. Tick Pin to taskbar and Pin to Start if you like, then Allow

Chrome

  1. Click the install icon at the right end of the address bar (or the Install button above)
  2. No icon? ⋮ › Cast, save, and share › Install page as app…

Firefox

  1. Click the Add to taskbar icon in the address bar (Firefox 143 or newer)

Updates arrive by themselves: the app always plays the live broadcast, and new jams show up as soon as they're added.
